# AITMPL Catalog source inventory

These files use the dashboard source from [davila7/claude-code-templates at 8c9a4a2](https://github.com/davila7/claude-code-templates/tree/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard). Vite publishes the original MIT notice from [AITMPL.LICENSE.txt](../../public/AITMPL.LICENSE.txt).

| Upstream | ASM file | Reuse and adaptation |
| --- | --- | --- |
| [ComponentGrid.tsx, toolbar and results](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/components/ComponentGrid.tsx#L347-L601) and [pagination](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/components/ComponentGrid.tsx#L860-L897) | [ComponentGrid.tsx](ComponentGrid.tsx) | Reuses the responsive type chips, search input, filter bar and panel, grid and list toggle, results header, page selection, and pagination JSX and Tailwind utilities. The type chips sit above the toolbar at desktop widths inside ASM's shared shell. The kind dropdown and repository chips use API metadata. Sort uses catalog order, name or repository; repository order adds a heading with a checkbox for each repository. Page selection is a checkbox. Page size is the original 24. |
| [ComponentGrid.tsx, grid and list cards](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/components/ComponentGrid.tsx#L602-L796) | [ComponentCard.tsx](ComponentCard.tsx) | Reuses the bordered card and row layouts, glyph tile, mono heading, clamped descriptions, metadata chip, entrance animation and plus SVG. Both views use the same component. The chip shows the native kind or an actual package component count, and a second chip names the source repository and filters by it. The title opens ASM's inspector or named package. A checkbox selects the entry; the plus opens ASM's menu of saved presets and stacks and saves the entry into the chosen one. Both stay visible for keyboard and touch. Saved presets open as packages. Components and saved stacks are selectable by their native catalog membership IDs. |
| [global.css](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/styles/global.css) and [DashboardLayout.astro font declarations](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/layouts/DashboardLayout.astro#L113-L127) | [catalog.css](catalog.css) | Scopes upstream light and dark theme values, Geist fonts and entrance animation to ASM's Catalog. The shell's theme switch applies the pinned dark values through the shared dark class. The CSS provides the Stack gradient alpha colors for Tailwind 3. Geist and Geist Mono WOFF2s come from Google Fonts and load locally. Their [Geist](../../public/Geist.OFL.txt) and [Geist Mono](../../public/GeistMono.OFL.txt) SIL Open Font License notices ship with the UI. |

Type icons and colors come from [kinds.ts](../lib/kinds.ts), which the preset pages share, instead of AITMPL's TypeIcon set. AITMPL's Stack drawer is replaced by the selection bar in [CatalogPage.tsx](CatalogPage.tsx) and the destination menu in [AddToMenu.tsx](AddToMenu.tsx).

ASM's catalog API supplies entries, source links and package counts. AITMPL's downloads, advertising, scan results, jobs, hosted collections, sharing, and Claude Code installation command depend on its service and are outside the local Catalog.
