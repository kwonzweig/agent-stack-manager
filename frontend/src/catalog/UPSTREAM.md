| [CartSidebar.tsx](https://github.com/davila7/claude-code-templates/blob/8c9a4a2c4a12a3010a0d26eddd3c40e7cef16af1/dashboard/src/components/CartSidebar.tsx#L194-L424) | [CartSidebar.tsx](CartSidebar.tsx), [CatalogPage.tsx](CatalogPage.tsx) | Reuses the counted floating Stack button, right drawer, header, clear action, grouped folder and file rows, removable selections and footer surfaces. ASM's catalog API supplies entries, source links and package counts. AITMPL's downloads, advertising, scan results, jobs, hosted collections, sharing, and Claude Code installation command depend on its service and are outside the local Catalog.
